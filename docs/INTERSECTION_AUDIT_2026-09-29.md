# 사거리 전수 점검 — 국내 횡단보도·정지선·신호 규칙 기준 (2026-09-29)

> **2026-09-29 파일 정리 후 참고**: 이 문서가 가리키는 캡처 이미지·백업 폴더는 삭제됐다(되돌리기 불가, HANDOFF AB번). 내용은 기록용으로만 남긴다.

도구: `scripts/audit_intersections.py`(점검), `scripts/tls_conflicts_traci.py`(신호 충돌),
`scripts/plan_crossing_fixes.py`(지울 횡단보도 + 보도 연결 유지), `scripts/add_missing_crossings.py`(입구 횡단보도
추가 + 해당 신호 재생성), `scripts/fix_ped_green.py`(보행 초록 시간).

## 1. 적용한 규칙

| 코드 | 규칙 | 근거 |
|---|---|---|
| CENTER | 사거리 한가운데(사거리 안쪽 연결 도로 위)에 횡단보도를 두지 않는다. 각 도로 입구, 사거리 중심 진입 직전에 둔다 | 도로교통법 시행규칙 별표6 532, 경찰청 교통노면표시 업무편람(교차로 모서리 설치), 사용자가 기준으로 든 사거리(cluster_436538601…) |
| DUPLICATE | 같은 차로를 10m 안에서 두 번 건너는 횡단보도는 하나만. 분리된 들어오는/나가는 차로를 따로 건너는 두 조각(가운데 보행섬)은 허용 | 시행규칙 제11조(횡단보도 간 거리), 532(보행섬) |

| PED_SHORT | 보행 초록 ≥ 7초 + 횡단 길이 ÷ 1.0m/s | 도로교통공단 보행신호 산정식 |

"사거리" = 20m 미만(같은 신호가 아니면 10m 미만) 차도로 이어진 갈림 교차점(이웃 3개 이상)들의 묶음 중 바깥 갈래가
3개 이상인 것. 사거리 앞 짧은 토막 끝(이웃 2개 이하 점)은 입구로 본다 - 이렇게 하지 않으면 토막 위 입구 횡단보도가
'한가운데'로 잘못 잡힌다. 신호 207개 중 사거리가 아닌 것(횡단보도 전용 신호 등, 갈래 2개 이하)은 사거리 점검
대상에서 빠지지만 보행 초록 시간(PED_SHORT)은 모든 신호에 적용.

### 신호 충돌에 대한 정정

9/28에 "cluster_13906093861·cluster_436538601 두 곳에서 신호 충돌"로 보고하고 G→g로 고쳤던 것은 **오탐**이었다.
net.xml 충돌표(foes)의 번호를 신호 링크 번호와 잘못 대응시킨 탓. SUMO에게 직접 내부 차선 충돌 목록
(`traci.lane.getInternalFoes`)을 물어 다시 보니 원본·수정 전·현재 net 모두 0건. 같은 방법으로 "보행 초록 중 차량은
양보(g)"인 정상 조합은 두 곳에서 9건씩 잡히므로 검사 자체는 작동한다. 그때의 G→g 수정은 필요 없었지만 해롭지도
않다(양보할 상대가 없으면 차량 동작이 같음).

## 3. 해결 방법 (도로·교차점 모양은 그대로)

1. CENTER·DUPLICATE: netconvert `<crossing node= edges= discard="true"/>`로 지움. 겹침은 신호가 있는 쪽, 없으면
   사거리 중심에 가까운 쪽을 남김.
2. 보도 연결 유지: 지우면 보행 연결 요소가 원래보다 쪼개지는 곳(작은 블록을 둘러싼 교차점의 횡단보도가 전부
   지워져 블록 보도가 섬이 되는 경우)은 다시 이어질 때까지 가장 적게 되살림(겹침으로 지운 것 먼저).
3. NO_CROSS: 그 입구 도로가 붙은 교차점에 횡단보도 추가, 해당 신호는 새 횡단보도까지 넣어 다시 만듦(9/26 신호
   합치기와 같은 netconvert 기본 90초 프로그램). 횡단보도를 지워 빈 신호 링크 번호가 남은 신호도 같이 다시 만듦.
4. PED_SHORT: 그 횡단보도가 초록인 단계 중 가장 긴 단계를 모자란 만큼 늘림(minDur도 같이).
5. STOPLINE: 신호 사거리 진입 도로에 정지 오프셋 3m(`<stopOffset value="3"/>`).
