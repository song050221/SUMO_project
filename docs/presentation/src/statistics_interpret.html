05해석 — 무엇이 좋아졌고, 무엇을 대가로 냈나

확실히 좋아짐 (5개 seed 전부 같은 방향)

-76%견인 568 → 134대
도로에 낀 채 못 빠져나간 차
-35%누적 대기시간
도로 위에서 멈춰 서 있던 시간
-14%총 시스템 통행시간(TSTT)

대가로 늘어남

평균 통행시간 +8% — 우회로 이동 거리가 늘고, 원래라면 낀 채 견인됐을 차가 늦게라도 도착해 평균에 들어온다(도착한 차만 세는 지표).

급제동 +15% — 사고 앞 감속·정지 명령과 경로 변경이 브레이크를 더 밟게 한다. 충돌은 늘지 않았다(-19%, 차이 없음).

읽을 때 주의할 점

  • 표본 5쌍: t-검정은 유의(p < 0.05). Wilcoxon은 5쌍이면 최솟값이 0.0625라 0.05 아래로 내려갈 수 없다 — 5개 모두 같은 방향이 이 검정의 최대치
  • TSTT는 견인된 차를 "끝까지 도착 못 한 차"로 1시간 끝까지 센다 → 견인이 줄면 크게 준다. 그래서 누적 대기시간과 견인을 주된 근거로 본다
  • 사고는 30초마다 가장 붐빌 도로에 나는 스트레스 조건. 실제 사고 빈도에서의 효과는 측정하지 않았다
  • 모든 차가 명령을 따른다는 V2N 보급률 100% 가정

예전 공식 결과(차이 없음)와 다른 이유

예전 비교는 중앙 제어 쪽에만 사고가 나는 불공정 조건이었다(사고가 감지 함수 안에서 만들어져 baseline엔 사고가 없었음). 이번엔 양쪽에 같은 규칙으로 사고를 내 차이가 알고리즘뿐이 되게 고쳤다. 도로망도 최신(사거리 합치기·재빌드)이다.
